# Weekly Reflection

Read `tools/weekly-reflection.md` and run it. Keep it to ~5 minutes: what moved forward, what stalled, and the one thing that matters most next week.

Then update `core/hot.md` with the new focus and capacity, update `core/goals.md` if a goal changed, and end with one specific next action. If the dashboard tool is on, offer to refresh it afterward.
