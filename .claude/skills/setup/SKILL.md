# Command Center Setup

Read `START-HERE.md` at the root of this command center and follow it exactly. It walks you through interviewing the user and building their `core/` files, then recommending tools, connectors, and skills.

Do not skip the runbook's rules — assume the user is not a developer, ask in small batches, write files as you go, and offer the mid-setup "first look" snapshot after the core files are written.
