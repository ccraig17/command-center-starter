# Tools

Tools are optional add-ons. Each one gives your assistant a new capability. Switch them on when you want them — one at a time. You don't need all of them, and you don't need them on day one. When a tool produces work (drafts, notes, plans), that work lands in your `workspace/` folder.

## Available tools

| Tool | What it does | Status |
|---|---|---|
| `weekly-reflection` | A 5-minute weekly check-in that keeps you honest and your focus current. **The anchor — start here.** | on |
| `calendar` | Preps your day, protects focus time, flags conflicts. | on |
| `content` | Turns your work into posts in your voice. | off |
| `opportunities` | Surfaces a few high-fit opportunities a week and filters the noise. | off |
| `connectors` | Connects your assistant to real apps (calendar, email, notes, tasks). | on |
| `dashboard` | An optional visual home page for your command center. No-install view, or a full local app. **Advanced.** | on (snapshot) |

## How to switch one on

Say "add a tool" or name it directly (e.g. "set up my calendar tool"). The assistant opens the tool's file, asks any setup questions, and marks it **on** in the table above.

Start with `weekly-reflection`. Add others only when the last one is actually working for you. Leave `dashboard` for last — it's the one advanced option.
