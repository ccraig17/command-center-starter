# Projects

This is where bigger, longer-running initiatives live — each in its own folder. A project is anything with a goal and a finish line that spans more than a quick task: launching something, a job search, planning an event, building a side thing.

Each project folder holds its own notes, plans, and progress. Your assistant creates one when you start something substantial, and checks in on them during your weekly reflection.

Quick, day-to-day work lands in `workspace/` instead, not here.
